## 一、功能完成情况

### 1. 账号体系

- 登录：账号支持手机号或邮箱，错误提示区分"账号不存在 / 密码错误"
- 注册：校验账号格式、密码强度、两次密码一致，重复账号拦截
- 登录态持久化：刷新、跳页不丢失；已登录访问登录页自动跳回首页
- 内置演示账号首次打开自动创建

### 2. 全站导航

- 一级栏目：首页 · 商品 · 新品 · CPhone · CPad · CBook · 配件
- **高亮跟随页面**：首页点亮"首页"，全品页点亮"商品"，分类页点亮对应栏目，从下拉点具体型号时点亮该型号所属分类
- 悬停展开分类下拉，内容由商品数据自动生成（新增商品无需改导航代码）
- 右侧：搜索框、购物车图标（实时角标）、头像、`Hi，昵称` 问候语、悬浮用户菜单
- 滚动时导航栏加阴影；390px 手机端自动收成紧凑布局

### 3. 首页

- **首屏双屏轮播**：CBook Fold Light（深金）⇄ CPhone ING（冰蓝），每 5 秒自动切换，底部两个胶囊按钮可手动切换，当前项内嵌进度条与计时同步；切后台自动暂停
- **分类入口区**（Collections · 2026）：CPhone / CPad / CBook / 配件四张卡片，悬停有位移与箭头反馈
- **新品探寻**：4 款（CPhone ING、CBook Fold Light、CMaxing、CWatch）
- **品牌故事区**（CIG-AI · On-device）：左侧文案、右侧产品图，带光晕背景
- **精选产品**：4 款（CBook Air X、CPairs、CPad Board、CPower-USB 充电头），无"查看全部"入口

### 4. 商品列表页

- 全部商品 + 按分类筛选（`?cat=`）、新品筛选（`?new=1`）、关键词搜索（`?q=`）
- 商品卡：实拍图、名称、副标题、价格、标签、新品角标、右下角一键加购"+"按钮
- **分类广告牌**：每个分类页顶部一张专属视觉横幅（详见第三章），随 `cat` 参数自动切换
- 商品顺序按需求定制：手机 ING → 21 → 21 Pro → 21 Pro Max → 20 → SG；平板 Lion 8 → SE → Air → Board；笔记本 Fold Light → TAI → Air X → Pro

### 5. 商品详情页

已完成 5 款，共用一套模板：

| 商品 | 价格 | 配色 |
| --- | --- | --- |
| CPhone ING | ¥5,999 | 冰海蓝（单色） |
| CPad Lion 8 | ¥3,299 | 酒红色 / 山水绿（切绿即变青绿） |
| CBook Fold Light | ¥14,999 | 曜石黑（单色） |
| CMaxing | ¥1,999 | 雾蓝（单色） |
| CWatch | ¥1,299 | 曙光金 / 甜美粉 |

页面结构：面包屑（跟随品类）→ 左侧图库（1 张大图 + 3 张缩略图，桌面端 sticky 跟随）→ 右侧标题 / 价格 / 标签 / 现货 / 一句话介绍 / 颜色选择 / 数量步进器 / 双按钮 / 四组折叠信息（产品介绍、规格参数、两个卖点长文）。

- **双按钮**统一"大海蓝"色系：加入购物车（浅底描边）、立即下单（实底渐变，加购并打开购物车）
- 数量受库存上限约束，缺货时按钮禁用
- 换色时保留当前浏览的图序（不跳回第一张）

### 6. 侧拉购物车

- 点击导航购物车图标，从右侧滑出 420px 抽屉（手机端全宽），带模糊遮罩，支持 Esc / 点遮罩 / 关闭按钮
- 加购、移除、改数量（1 时减号禁用）、单项小计、购物车合计、清空（两段确认防误触）
- 数据存 `localStorage`，刷新与跳页不丢；**跨标签页实时同步**（一个标签加购，另一个标签角标立刻变）
- 数据校验：已下架商品自动剔除、重复项合并、数量夹在 `1 ~ min(99, 库存)`、缺货不可加购

### 7. 结算与下单

- 单页结算：左侧收货地址 / 配送方式 / 支付方式 / 备注，右侧订单摘要（桌面端吸顶）
- 地址簿打通个人中心：可切换、可删除；无地址时在页内直接新增（省市区三级联动 + 家/公司/学校标签 + 设为默认）
- 三种支付：微信 / 支付宝弹出**模拟二维码**（canvas 现绘，带"模拟二维码"角标）；银行卡弹出卡号/有效期/CVV 表单（自动格式化）
- 提交订单 → 写入本地订单 → 清空购物车 → 跳转下单成功页（订单号、实付、支付方式、收货信息、商品清单）

### 8. 个人中心

- 左侧索引导航：基本资料 · 我的订单 · 收货地址，滚动自动高亮
- 基本资料：头像、昵称、性别、生日、账号信息
- **我的订单**：订单卡片列表（订单号、时间、商品缩略图、名称、件数、支付方式、金额、「准备发货」状态、查看订单跳转），空态引导去逛逛
- 收货地址：多地址管理（新增/编辑/删除/设为默认，最多 10 条）

### 9. CSHOP 礼宾（AI 导购助手）

- 入口：任意页面右下角悬浮按钮，打开为双栏面板（左对话、右选购上下文）
- 10 个业务工具：`searchProducts` / `getProduct` / `compareProducts` / `buildBundle` / `getCart` / `listAddresses`（只读）+ `addToCart` / `updateCartItem` / `removeFromCart` / `createOrder`（写操作，需用户确认）
- 流式回复、执行过程卡片、快捷问句（预算选平板、配齐配件、看购物车、机型对比）
- 选购上下文实时统计：预算、购物车件数、工具调用次数、方案生成次数、对比次数
- 后端代理隔离 API Key；未连接时降级提示，不影响主站

## 二、视觉与素材工艺

这部分是这个项目投入最多的环节，也是"看起来像真站"的关键。

### 1. 首屏双屏轮播

两张主视觉都用图像生成 + 二次处理得到。融合方式按布局分两套：

- **桌面双栏**：图片放大到超出容器，右/上/下三条边被卡片裁掉，只剩左缘一条边用渐变遮罩淡出——看不到任何矩形边界
- **单列（平板/手机）**：不使用图片元素，直接把图设为卡片背景，顶部叠深色渐变保证文字可读，从根上消除接缝

切换用 `translateX` + 0.92s 缓动曲线，非当前屏的文案与产品图额外位移并降透明度，形成层次感；系统开启"减少动态效果"时只关闭过渡动画，自动轮播照常（早期版本误把轮播一起关掉，已修正）。

### 2. 分类广告牌

每个分类页顶部一张专属视觉横幅，由 `html.is-cphone` 之类的类名在 CSS 层控制显隐，因此同一份 HTML 能按分类呈现不同画面：

| 广告牌 | 分类 | 主题文案 |
| --- | --- | --- |
| CPhone ING | 手机 | AI 强大赋能，多姿又多彩 |
| CPad Lion 8 | 平板 | 灵感，随身流动 |
| CBook Fold Light | 笔记本 | 两块屏，一整块灵感 |
| CMaxing 静界 | 配件 | 世界很吵，戴上就静 |
| 新品三面来见 | 新品页 | CPhone ING、CPad Lion 8、CMaxing 同台 |

素材为 AI 生成后抠图（cutout）与背景分离，配合光斑、流体、颗粒等装饰层做纵深。

### 3. 商品详情图处理工艺

五款商品的原素材都是竖版长海报，统一按以下流程处理成三张方形图：

1. **分段裁切**：按内容切成「整机 / 细节 / 特写」三段，保留海报上的标题、副标题、价格与标签文案（不裁字）
2. **避开分隔线**：把裁切起点下移几个像素，避免把段间的灰色细线带进图片上沿
3. **白点归一**：三段底色往往不一致（偏白、偏粉、偏灰），先按通道乘增益把白点拉到同一底色，再合成，切换图时不会"跳色调"
4. **边羽化**：只对图片自己的四条边做渐隐，画面四周自然融进画板，看不到矩形
5. **顶边特殊处理**：个别素材的部件在原始海报里就被切断（如耳机头梁），单独加大顶边淡出，让它像"渐隐"而不是"裁坏"
6. **缩略图另出**：按与底色的差异求主体包围盒，再方形裁切放大，避免宽图缩略图里主体只有指甲盖大

### 4. 换色工艺（双色商品）

不做整图滤镜，而是按"色相区间 + 色度"双门槛筛选像素再偏色：

- CPad Lion 8：酒红 → 青绿，色相 +180°，只作用于机身与屏幕，浅色背景不动
- CWatch：曙光金 → 甜美粉，只对金色色相带偏移，屏幕上的红/绿/蓝运动圆环、黑色表盘、米白背景全部保持原样

早期曾用 HSL 饱和度做权重，结果近白色背景被判为"高饱和"，整张图泛绿；改用色度 `(max-min)/255` 后解决。

### 5. 配色与版式

- 全站浅色极简底（`#fbfbfd → #f2f4f8`），深色首屏作为对比
- 详情页双按钮统一"大海蓝" `#0d5c8c`，一浅一深区分主次
- 标题层级、卡片圆角、阴影克制，移动端 390 / 768 / 1024 / 1440 四个宽度逐一验证

## 三、技术实现

| 方面 | 做法 |
| --- | --- |
| 数据源 | `js/products.js` 单一数据源，导航下拉、分类页、首页区块、搜索结果全部由它派生；新增商品只改一处 |
| 购物车状态 | 自建发布订阅：`localStorage` 持久化 + `commit()` 统一"写盘 → 重渲染 → 通知订阅者"，导航角标订阅更新；监听 `storage` 事件实现跨标签同步 |
| 订单存储 | `cshop_orders_<账号>`，最新在前，最多保留 30 单 |
| 省市区 | 内置 `js/regions.js`（约 88 KB 三级数据），离线可用 |
| 无外部依赖 | 无 CDN、无 npm、无构建；图标全部内联 SVG；二维码为 canvas 现绘伪码 |
| 兼容与可移植 | 全部相对路径，克隆到任意目录、任意静态服务器都能直接跑 |
| 响应式 | 断点 1080 / 900 / 720 / 560，单列时产品图改为卡片背景或满宽贴底 |

页面清单：`index.html` 首页、`products.html` 商品列表、`product.html` 详情、`checkout.html` 结算、`order.html` 下单成功、`profile.html` 个人中心、`login.html`、`register.html`。

## 四、工作分工与推进顺序

项目由两个 AI 编码环境接力完成，以下按实际推进顺序整理。

### 第一阶段：基础框架（WorkBuddy）

登录注册 UI 与校验逻辑 → 全站导航与分类下拉 → 首页（首屏、新品、精选）→ 商品列表与筛选搜索 → 个人中心（资料、地址簿、省市区联动）→ 商品数据与图片统一处理 → 侧拉购物车（状态管理 + 跨标签同步）。

### 第二阶段：视觉升级（WorkBuddy）

首屏从浅色卡片改为深金质感折叠本主视觉 → 增加 CPhone ING 第二屏并做成 5 秒轮播（含切换按钮与进度条）→ 双色商品换色工艺 → 五款商品详情页（三次迭代：初版裁太紧丢字 → 恢复文案 → 调整顶边淡出）。

### 第三阶段：交易闭环（WorkBuddy）

五个商品详情页 → 结算页（地址、配送、支付、备注、摘要）→ 三种支付的模拟实现 → 下单成功页 → 个人中心「我的订单」区块（状态显示"准备发货"）。

### 第四阶段：视觉扩写（Qoder）

- **分类广告牌体系**：为手机 / 平板 / 笔记本 / 配件 / 新品各做一张全屏视觉横幅，共 5 套独立样式（`billboard.css` 及四份分类样式），通过 `html.is-cat` 类名切换
- **首页编辑风区块**：新增 `editorial.css`，「按你的方式，组一套设备」四张分类卡 + 「AI 不在云端，在指尖」品牌故事区，重排首页叙事顺序
- **素材制作**：AI 生成背景与产品抠图（`assets/billboard/` 11 个文件，含 cutout 透明图与背景图）

### 第五阶段：整合与发布（WorkBuddy）

全站回归（8 页 + 5 详情 + 购物车 + 结算 + 订单，无 404、无 JS 报错）→ 发布目录重建（115 个文件 / 9.7 MB）→ 线上部署与真实流程验证。

### 第六阶段：AI 礼宾与体验打磨（Qoder + WorkBuddy）

**Qoder 部分**

- **CSHOP 礼宾（AI 导购助手）**：`js/assistant.js`（约 3300 行）+ `js/assistant-tools.js` + `css/assistant.css`
  - 右下角悬浮入口，打开为左对话、右「选购上下文」的双栏面板
  - 接入 10 个业务工具：6 个只读（检索商品、查详情、对比、搭组合、看购物车、列地址）+ 4 个写操作（加购、改数量、移除、下单），写操作必须用户确认
  - 流式回复、执行过程可视化（调用了什么工具、耗时、结果条数）、快捷问句
  - 后端 `server/ai-proxy.js`：DeepSeek 代理，Key 只在服务端；`server/mock-ai.js` 供无 Key 时联调
  - 线上端点方案：`js/ai-endpoint.js` 按域名注入反向隧道地址，服务端 CORS 白名单加线上域名
- **详情页双按钮下方的配送提示**、结算与订单页的若干细节统一

**WorkBuddy 部分**

- 下单成功页新增「下单时间」，精确到秒（`YYYY-MM-DD HH:mm:ss`）
- 商品页搜索结果标题改为「“关键词”的搜索结果」，带 `?q=`、页内搜索、清空搜索三种情况都自动跟随
- 搜索框放大镜由装饰图形改为提交按钮，点击与回车完全等效，并补齐悬停 / 按下 / 键盘聚焦反馈
- 多轮发布与线上验证（含 CDN 缓存排查、CORS 与隧道连通性确认）

## 五、当前状态

- 线上为最新版本，浏览器直接打开链接即可使用
